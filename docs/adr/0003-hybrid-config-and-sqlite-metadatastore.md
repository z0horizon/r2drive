# 0003: Trait-Based MetadataStore Abstraction Supporting SQLite and PostgreSQL

To allow users to configure either SQLite (`sqlite:///data/r2drive.db`) or PostgreSQL (`postgres://user:pass@host:5432/db`) in `config.yaml`, `r2drive` establishes a trait-based repository architecture (`MetadataRepo`) from day one. Rather than relying on `sqlx::Any` (which introduces parameter rewriting bugs and lacks rich type support), the database layer isolates engine-specific logic into `SqliteMetadataRepo` and `PostgresMetadataRepo` with separate migration directories (`migrations/sqlite/` and `migrations/postgres/`). Phase 1 implements the SQLite repository with pure SQLite types, while the architecture natively accommodates the PostgreSQL backend in Phase 2 without modifying domain or handler logic.
