# 0009: WebConsole Built with Svelte 5, Vite, and Tailwind CSS

Adopt Svelte 5 with Vite and Tailwind CSS for the `WebConsole` single-page application. Svelte 5's compiler architecture eliminates virtual DOM overhead, produces an ultra-compact bundle (~40 KB gzipped) ideal for single-binary embedding via `rust-embed`, and simplifies multi-part direct upload state management through native reactivity runes (`$state`).
